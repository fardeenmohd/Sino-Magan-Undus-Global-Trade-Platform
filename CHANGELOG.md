# Changelog

All notable changes to Project Antigravity will be documented in this file.

## [Unreleased]

### Added
- **Cross-Device Responsive Layout Optimization Across Mobile, Tablet, Laptop, PC & Ultrawide Screens**:
  - **Ultrawide Monitor Expansion (`≥1536px`)**: Expanded maximum layout wrappers to `2xl:max-w-[1600px]`, allowing 5-column product catalog grids (`2xl:grid-cols-5`) and 8-column destination corridor grids (`2xl:grid-cols-8`) for wide-screen monitors.
  - **Desktop / Laptop (`1024px-1536px`)**: Optimized 4-column catalog grid (`lg:grid-cols-4`) and 4-column KPI cards (`lg:grid-cols-4`).
  - **Tablet (`640px-1024px`)**: 2 to 3-column responsive catalog grids (`sm:grid-cols-2 md:grid-cols-3`) with flexible wraps and side-by-side forms.
  - **Mobile (`<640px`)**: Stacked single-column layouts (`grid-cols-1`), touch-scrollable navigation tab bar (`overflow-x-auto whitespace-nowrap`), and touch-friendly padding.

- **Complete Platform Rebrand to "Sino Magan Undus Global Trade"**:
  - Rebranded application header, document titles, layout metadata, landing page hero section, user dashboard, login/register authentication portals, and package metadata.

- **Custom Target Destination Support & Dynamic Landing Page Corridor Showcase**:
  - Exporters and Importers can specify **`✨ Custom Destination / New Country`** in both Landing Page & Dashboard publishers.

- Initialized workspace with `AGENCY_CONSTITUTION.md` standing instruction set.
